Each cell has at most one outgoing edge.</span></p><p dir="ltr"><span style="font-size: 14pt;">For every cell i:</span></p><ul><li value="1"><span style="font-size: 14pt;">edge[i] is the cell reached from i in one step.</span></li><li value="2"><span style="font-size: 14pt;">edge[i] = -1 means that cell i has no outgoing edge.</span></li></ul><p dir="ltr"><span style="font-size: 14pt;">A cycle is a sequence of cells where, by following the outgoing edges, we eventually return to the starting cell.
