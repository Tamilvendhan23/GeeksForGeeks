<h2><a href="https://www.geeksforgeeks.org/problems/good-stones--170647/1">Count Indices That Escape Array</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an array <strong>arr[]</strong>, where arr[i] represents the exact number of steps to move from index i.&nbsp;&nbsp;</span><span style="font-size: 14pt;">An index is considered good if repeatedly following the jumps eventually takes you outside the array. Otherwise, if the jumps result in an infinite loop, the index is considered bad. </span></p><ul><li><span style="font-size: 14pt;">A positive value indicates a move to the right</span></li><li><span style="font-size: 14pt;">A negative value indicates a move to the left.</span></li><li><span style="font-size: 14pt;">A 0 value&nbsp;</span><span style="font-size: 14pt;">means no move </span><span style="font-size: 14pt;">and considered bad.</span></li></ul><p><span style="font-size: 14pt;">Return the number of good indices.</span></p><p><strong><span style="font-size: 18px;">Examples:</span></strong></p><pre><span style="font-size: 18px;"><strong>Input:</strong> [2, 3, -1, 2, -2, 4, 1]</span>
<span style="font-size: 18px;"><strong>Output: </strong>3
<strong>Explanation: </strong>Indices 3, 5, and 6 are good because their jump sequences eventually leave the array. Indices 1, 2, and 4 form a cycle, while index 0 eventually enters this cycle through index 2. Hence, the total number of good indices is 3.
</span><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/713990/Web/Other/blobid0_1745470372.jpg" width="464" height="232"> </pre><pre><span style="font-size: 18px;"><strong>Input:</strong> [1, 0, -3, 0, -5, 0]</span>
<span style="font-size: 18px;"><strong>Output:</strong> 2
<strong>Explanation: </strong>Indices 2 and 4 are good because their jumps take them outside the array. Indices 1, 3, and 5 are bad because their jumps are zero. Index 0 is also bad because it jumps to index 1, which is a dead end. Hence, the total number of good indices is 2.
