On Day 2, we replace s[p[1]] (index 1) with '?'. String becomes "a??b". Now no two adjacent non-'?' characters are equal.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> s = "abca", p = [3, 0, 2, 1]
<strong>Output:</strong> 0
<strong>Explanation:</strong>
