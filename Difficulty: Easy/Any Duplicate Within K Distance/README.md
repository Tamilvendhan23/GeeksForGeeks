<h2><a href="https://www.geeksforgeeks.org/problems/kth-distance3757/1">Any Duplicate Within K Distance</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an array of integers, <strong>arr[]</strong> and an integer <strong>k</strong>, check whether there exist two distinct indices i and j such that<strong> </strong>arr[i] is equal to arr[j] and the absolute difference between i and j is at most k.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [1, 5, 4, 5, 1], k = 3</span><br><span style="font-size: 14pt;"><strong>Output: </strong>true</span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> The element 5 occurs at indices 1 and 3. Their distance is |3 - 1| = 2, which is less than or equal to k.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [10, 2, 3, 4, 10, 5], k = 3</span><br><span style="font-size: 14pt;"><strong>Output:</strong> false</span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> The element 10 occurs at indices 0 and 4. Their distance is |4 - 0| = 4, which is greater than k. Hence, no duplicate exists within the given distance.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [5, 1, 3, 2, 4], k = 3</span><br><span style="font-size: 14pt;"><strong>Output:</strong> false</span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> All elements are distinct, so no duplicate exists.</span></pre></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Amazon</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Hash</code>&nbsp;
