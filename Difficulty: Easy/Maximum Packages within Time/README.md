<h2><a href="https://www.geeksforgeeks.org/problems/bird-and-maximum-fruit-gathering0509/1">Maximum Packages within Time</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">A delivery agent has to deliver packages at locations arranged in a line. The number of packages at the<strong> ith</strong> location is given by <strong>arr[i]</strong>. </span></p><ul><li><span style="font-size: 14pt;">The agent can start at any location and can only visit consecutive locations.</span></li><li><span style="font-size: 14pt;">Visiting each location takes 1 unit of time.</span></li></ul><p><span style="font-size: 14pt;">Given <strong>arr[]</strong> and <strong>totalTime</strong>, find the maximum number of packages the agent can deliver within <strong>totalTime</strong>.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 18.6667px;"><strong>Input: </strong>arr[] = [2, 1, 3, 5, 0, 1, 4], totalTime = 3
<strong>Output:</strong> 9
<strong>Explanation:</strong> The agent can visit three consecutive locations. Starting from the second location, it delivers arr[1] + arr[2] + arr[3] = 1 + 3 + 5 = 9 packages.</span></pre><pre><span style="font-size: 18.6667px;"><strong>Input:</strong> arr[] = [1, 6, 2, 5, 3, 4], totalTime = 2
<strong>Output:</strong> 8
<strong>Explanation: </strong>The agent can visit two consecutive locations. Starting from the second location, it delivers arr[1] + arr[2] = 6 + 2 = 8 packages. Starting from the fourth location gives arr[3] + arr[4] = 5 + 3 = 8 packages. Hence, the maximum is 8 packages.</span></pre></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Facebook</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>sliding-window</code>&nbsp;<code>two-pointer-algorithm</code>&nbsp;
