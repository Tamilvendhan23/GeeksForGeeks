<h2><a href="https://www.geeksforgeeks.org/problems/trace-path3840/1">Trace Path</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a rectangular grid with <strong>n </strong>rows and <strong>m </strong>columns, and a string <strong>s</strong> representing a sequence of movement commands. Geek can start from any cell of the grid and follows all the commands in s in the same order.</span></p><p><span style="font-size: 14pt;">The string s consists only of the characters L, R, D, and U, where:</span></p><ul><li><span style="font-size: 14pt;">L: Move one cell left, from (i, j) to (i, j - 1).</span></li><li><span style="font-size: 14pt;">R: Move one cell right, from (i, j) to (i, j + 1).</span></li><li><span style="font-size: 14pt;">D: Move one cell up, from (i, j) to (i - 1, j).</span></li><li><span style="font-size: 14pt;">U: Move one cell down, from (i, j) to (i + 1, j).</span></li></ul><p><span style="font-size: 14pt;">Determine whether there exists at least one starting cell such that Geek remains within the grid after performing all the commands in s.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input:</strong> n = 1, m = 1, s = "R"
<strong>Output:</strong> false
<strong>Explanation:</strong> There is only one cell(1, 1). So Geek can only start from (1, 1). On taking right(R) Geek moves to (1, 2), which is out of grid. Therefore, there is no cell from where Geek can start and remain inside the grid after tracing the route. </span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> n = 2, m = 3, s = "LLRU"
<strong>Output:</strong> true
<strong>Explanation:</strong> One possible cell is (1, 3). (1, 3) -&gt; (1, 2) -&gt; (1, 1) -&gt; (1, 2) -&gt; (2, 2). Thus, there is a cell from where if Geek starts, it remains inside the grid throughout tracing the route.<br></span><img style="max-width: 98%; margin: 1%; width: 386px; height: 193px;" draggable="false" src="https://media.geeksforgeeks.org/wp-content/uploads/20260923174149914643/frame_3972.webp" alt="frame_3972"></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Matrix</code>&nbsp;
